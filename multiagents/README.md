### 快速开始  
1. 安装依赖（python=3.10）：  
```bash  
pip install -r requirements.txt  
```  
2. 在`gui_app.py`第318行添加API_KEY，运行程序：  
```bash  
python gui_app.py  
```  
3. 输入音乐描述，点击"生成音乐代码"按钮，等待多智能体系统生成代码。会很慢，大概需要3分钟。**（优化点1）** 生成的代码会自动保存为midi文件。  
4. 点击"反馈"按钮，将报错或改进要求输入，生成新一版代码。一般2-3次才能出声。**（优化点2）**  
5. 点击"风格迁移"按钮，输入要迁移的风格，得到新的一版代码，手动复制粘贴进去运行。（这一块缝合了@刘新泉同学的代码，在`style_transfer.py`里）  
6. 运行程序时，请确保 **Sonic Pi** 已打开并运行。  
### 思路讲解
总体思路基本不变：  
> 输入文本生成一段midi，生成的midi经过风格迁移改善迭代（这里可以用到代码），迭代后通过前端合成器输出音乐  

细节：  
> 先让多智能体生成代码，再把代码翻译为midi。此处有尝试从sonic-pi输出直接提取midi（Windows电脑使用[loopmidi](https://www.tobias-erichsen.de/software/loopmidi.html)），但是prompt engineering出来的效果很烂，遂放弃。**（优化点3）** 翻译好的midi再进行风格迁移，得到新代码和新midi。  

多智能体逻辑：  
按照时间顺序  
1. Translator翻译官：把用户输入的直白要求翻译成较为专业的音乐术语。  
2. Composer作曲家：根据翻译官的翻译结果生成一段代码。  
3. Critic评论家：对作曲家生成的代码进行评价，给出评分和反馈。  
4. Arranger调教师：根据评分和反馈，对作曲家生成的代码进行修改，生成新的代码。  
5. Compiler编译器：将生成的代码翻译成midi文件，保存在本地。
